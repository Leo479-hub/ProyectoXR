# Museum Guide AR

**Museum Guide AR** es una aplicación de realidad aumentada desarrollada en Unity y Vuforia que busca enriquecer la experiencia de aprendizaje sobre el patrimonio cultural peruano. A través del reconocimiento de marcadores (Image Targets), los usuarios pueden visualizar modelos 3D de piezas arqueológicas representativas, acompañadas de títulos informativos y audios descriptivos que brindan contexto histórico y cultural.

El proyecto incluye una interfaz amigable con un menú principal, exploración interactiva de diferentes piezas del museo y recursos multimedia diseñados para dispositivos móviles. Su objetivo es ofrecer una experiencia educativa e inmersiva que acerque el conocimiento del patrimonio cultural mediante el uso de tecnologías de realidad aumentada.

### Características principales

* Reconocimiento de marcadores mediante Vuforia.
* Visualización de modelos 3D de piezas arqueológicas.
* Paneles informativos con títulos descriptivos.
* Reproducción de audios explicativos para cada pieza.
* Menú principal para acceder a la experiencia.
* Optimización orientada a dispositivos móviles Android.
